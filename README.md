📦 FEMA Disaster Supply Chain Analytics Project
🔍 Overview
This project analyzes real FEMA disaster supply‑chain data to identify bottlenecks, shortages, delays, and supplier performance issues during emergency operations. The goal is to improve readiness, optimize resource allocation, and support federal emergency response missions.

🎯 Objectives
Clean and prepare FEMA shipment data using SQL

Identify supply shortages and delivery delays

Analyze supplier reliability and transportation modes

Evaluate warehouse performance across FEMA regions

Build dashboards showing readiness and bottlenecks

Provide actionable recommendations for federal operations

🛠️ Tools Used
SQL (cleaning + analysis)

Python (EDA + visualizations)

Power BI / Tableau (dashboard)

GitHub (version control + documentation)

📁 Repository Structure
/data          → FEMA datasets (raw + cleaned)
/sql           → SQL cleaning + analysis scripts
/notebooks     → Python analysis notebooks
/dashboard     → Power BI or Tableau files
/reports       → Final analyst report
